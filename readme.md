
# Meu Portfólio Pessoal

## Nome do aluno
Isabella Marinho Duarte

## Descrição
Este projeto consiste em um portfólio pessoal
desenvolvido para apresentar meu perfil,
projetos e habilidades na área de
Desenvolvimento de Sistemas.

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Bootstrap)

## Link do site publicado
[https://isabella-duarte.github.io/meu-portfolio/](https://isabella-duarte.github.io/Meu-Portifolio/)

## Funcionamento do projeto
O site possui um menu de navegação que permite
acessar as seções Perfil, Projetos, Habilidades
e Contato.

A seção Perfil apresenta informações pessoais.
A seção Projetos exibe atividades desenvolvidas.
A seção Habilidades apresenta as tecnologias
estudadas e a seção Contato disponibiliza
links para comunicação.

O Bootstrap foi utilizado para construir
um layout responsivo, adaptado a computadores
e dispositivos móveis.

## Recurso novo adicionado
Foram adicionados dois recursos:
uma seção de habilidades e animações
nos cards dos projetos.

## Como o recurso foi implementado
A seção Habilidades foi desenvolvida com HTML
e CSS, utilizando elementos visuais para
destacar as tecnologias estudadas.

As animações foram implementadas por meio
da propriedade CSS transition e do
seletor :hover, que desloca os cards
quando o usuário passa o mouse sobre eles.

Esses recursos melhoram a experiência
visual e tornam o portfólio mais interativo.
